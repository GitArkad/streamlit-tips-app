# streamlit-tips-app
## Визуализация dataframe `tips`

### Приложение состоит их 3х вкладок и визуализирует зависимость чаевых от иных показателей

**Вкладка main**
- общая информация

**Вкладка load data**
1. Скачивается файл в формате csv по выбору
2. Датафрейм выводится на экран
3. Выводится статистика (describe)

**Вкладка show data**
1. Выбор типа графика для визуализации
2. Выбор столбцов в графике для визуализации
3. Сохранение графиков в файл PNG (при падении в SVG), путь по умолчанию системы

файл с тестовыми данными
'https://raw.githubusercontent.com/mwaskom/seaborn-data/master/tips.csv'

Комментарий: не зависит от количества колонок и их названий.

Ограничение: соответствие типов, пропущеные значения
